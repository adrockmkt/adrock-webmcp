# v0.6.7 Regression and Security Tests Validation

Status: VALIDATED

Date: 2026-09-25

## Objective

Validate the regression, integrity and security contracts introduced by v0.6 Content Retrieval before starting the grounding benchmark.

## Validated contracts

### Canonical slug contract

The article store canonicalizes public slugs before creating retrieval artifacts.

The search runtime now returns the canonical retrieval slug while preserving the original public article URL.

The known encoded zero-width-space case is covered explicitly:

- public/index slug: `google-sponso%E2%80%8Bred-results-nova-interface-anuncios`
- retrieval slug: `google-sponsored-results-nova-interface-anuncios`
- artifact: `blog-articles/google-sponsored-results-nova-interface-anuncios.json`

Canonical slug collisions are detected before article-content fetching and fail closed.

### Retrieval allowlist and path safety

`get_blog_article` accepts only strict canonical slugs.

The runtime retrieves an article only when it exists in the generated manifest.

Manifest paths must be exactly:

`blog-articles/<canonical-slug>.json`

Unsafe slugs, unknown slugs, path traversal and tampered manifest paths are rejected.

### Public-origin restriction

Manifest and article URLs must resolve to the public Ad Rock origin and `/blog/` path:

`https://adrock.com.br/blog/*`

External origins are rejected.

### Manifest integrity

The runtime validates:

- schema version;
- non-negative integer article count;
- article count equal to the manifest entries;
- valid and unique canonical slugs;
- approved public article URLs;
- exact artifact paths;
- non-negative integer character and byte lengths.

### Artifact integrity

The runtime validates:

- requested slug equals artifact slug;
- artifact URL equals manifest URL;
- artifact URL remains inside the approved public blog;
- content is a non-empty string;
- actual JavaScript character length equals manifest metadata;
- actual UTF-8 byte length equals manifest metadata;
- artifact length metadata equals manifest metadata.

### Search to retrieval integration

An integrated regression test executes the real public tool contract:

`search_blog(query) -> canonical slug -> get_blog_article(slug) -> approved normalized content`

The encoded-slug edge case is used as the integration fixture.

The test also verifies that retrieval performs only the expected manifest request and the allowlisted article-artifact request.
